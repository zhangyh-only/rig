# 项目类型模板：mixed

适合：代码、配置、文档、知识库、生成物同时存在的项目。

## 应启用的规范层
- [B桶] `AGENTS.md` 必须说明哪些目录是源码、哪些是资料、哪些是生成物。
- [B桶] `docs/conventions/` 同时包含代码规则和资料规则，但要分文件管理。
- [A桶] `scripts/lint-one.sh` 覆盖源码；资料类文件按需接 Markdown、JSON、YAML 或链接检查。
- [A桶] `scripts/verify-local.sh` 同时验证代码可运行和关键资料产物可生成或可校验。

## 默认边界规则
- [B桶] 代码不能偷偷依赖未纳管的本地资料路径；资料路径要配置化或写入明确约定。
- [B桶] 生成物必须标明来源、生成命令和是否允许手改。
- [B桶] 文档更新不能只改结论，不更新支撑材料、样例或验证结果。
- [B桶] 代码改动影响资料结构时，要同步更新资料规范；资料口径变化影响代码逻辑时，要同步补测试或验收脚本。

## 收尾口径
- 同时报告代码验证和资料校验。
- 明确哪些产物是自动生成，哪些是人工编辑。
- 对未能验证的资料来源或运行环境单独列风险。
