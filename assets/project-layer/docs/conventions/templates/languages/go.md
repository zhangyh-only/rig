# 语言模板：Go

适合：Go 服务、CLI、基础设施工具、后台任务。

## 命名与结构
- [A桶] 使用 gofmt/goimports，包名短小且表达职责。
- [B桶] package 边界跟随项目现有结构，不为了复用过早抽公共包。
- [B桶] CLI 参数、配置和环境变量集中定义，默认值清晰。
- [B桶] 对外暴露的类型和函数要有注释，说明职责和约束。

## 错误与上下文
- [B桶] 错误要携带足够上下文，不静默忽略。
- [B桶] 可取消、可能阻塞或远程调用的流程传递 `context.Context`。
- [B桶] 日志包含定位问题所需的 key，但不泄露敏感信息。

## 检查器建议
- [A桶] gofmt/goimports：格式和 import。
- [A桶] go test：单测和竞态相关测试。
- [A桶] golangci-lint：常见错误、未使用代码、复杂度和安全项。

## 验证建议
- 库代码：聚焦 `go test ./...` 或受影响包测试。
- CLI：`--help`、dry-run、样例输入输出。
- 服务：本地配置 + smoke 请求 + 关键失败路径测试。
