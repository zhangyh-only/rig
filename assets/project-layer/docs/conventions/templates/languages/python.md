# 语言模板：Python

适合：Python 服务、脚本、数据处理、自动化工具、AI/LLM 辅助脚本。

## 命名与结构
- [A桶] 包、模块、函数、类命名跟随 PEP 8 和项目现有风格。
- [B桶] 脚本入口和库函数分开；可复用逻辑不要藏在 `if __name__ == "__main__"` 里。
- [B桶] 输入输出路径、模型名、远端地址、密钥和环境变量集中管理。
- [B桶] 数据处理流程要能说明来源、转换和输出位置。

## 类型、异常与数据
- [B桶] 公共函数尽量写类型标注，复杂数据结构用 dataclass、TypedDict 或 Pydantic 等项目已有方式表达。
- [B桶] 外部输入、文件读取、网络调用要处理失败路径。
- [B桶] 批处理脚本默认记录进度和失败项，避免中途失败后无法续跑。

## 检查器建议
- [A桶] ruff：lint 和格式。
- [A桶] mypy 或 pyright：关键模块类型检查，按项目成熟度启用。
- [A桶] pytest：单元测试、回归样例、数据处理样例。

## 验证建议
- 小脚本：`--help`、dry-run、样例输入输出。
- 数据处理：固定小样本回归，核对行数、字段和关键统计。
- AI/LLM 脚本：记录 prompt、模型、参数、输入样本和可复现的评估结果。
