# 资料模板：Markdown / 文档 / 知识库

适合：Markdown 文档、知识库、方案报告、产品说明、面试材料、课程资料。

## 结构与命名
- [B桶] 文件名、日期目录、版本号跟随项目现有规则。
- [B桶] 每份核心文档写清用途、适用范围、输入材料和更新时间。
- [B桶] 长文优先稳定标题结构，增量更新时保留原骨架。
- [B桶] 输出给业务方的文档先讲结论、价值和行动，再补机制和细节。

## 来源与事实
- [B桶] 明确区分原文事实、推断、建议和待确认项。
- [B桶] 不确定的日期、数据、姓名、产品名、版本号必须核对或标注待确认。
- [B桶] 不能因为工具抽取失败就写成“材料不存在”；应换抽取路径或说明技术限制。
- [B桶] 引用外部资料时保留来源链接或文件路径。

## 检查器建议
- [A桶] markdownlint：标题层级、列表、空行等格式。
- [A桶] 链接检查：内部锚点、相对路径、外部 URL。
- [A桶] 自定义脚本：日期目录、文件命名、必填章节。

## 验证建议
- 核对输入材料是否全部覆盖。
- 核对输出模板是否完整。
- 对高风险事实做二次检查。
- 标出未验证、延期或需要真人确认的事项。
